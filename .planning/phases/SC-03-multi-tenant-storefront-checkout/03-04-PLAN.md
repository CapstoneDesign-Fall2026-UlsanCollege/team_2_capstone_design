       - Return orders with aggregated items, customer details, and computed status counts (`new_count`, `packed_count`, `shipped_count`, `delivered_count`).
    2. `MerchantOrderDetailView` (`GET /api/merchant/stores/<storeSlug>/orders/<int:orderId>/`):
       - Returns full order details, items, events timeline, and delivery address snapshot.
    3. `MerchantOrderStatusTransitionView` (`POST /api/merchant/stores/<storeSlug>/orders/<int:orderId>/transition/`):

         - `CONFIRMED / PAID` → `PROCESSING` (Packed)
         - `PROCESSING` → `SHIPPED`
         - `SHIPPED` → `DELIVERED` (for COD, automatically sets `payment_status="PAID"`)
       - Appends `OrderEvent` with actor user, previous status, next status, and optional tracking note.
    4. Add typed API methods in `frontend/src/lib/api.ts`.
