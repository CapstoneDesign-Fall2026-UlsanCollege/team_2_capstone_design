<task type="tracer">
  <name>Task 1: Subscription Service & Checkout Activation</name>
  <files>backend/subscriptions/services.py, backend/stores/api.py, backend/subscriptions/models.py</files>
  <action>
    1. Create `backend/subscriptions/services.py`:
       - `create_subscription_from_order(order, variant, selling_plan)`:
         - Creates or updates `Subscription` record in status `ACTIVE`.
         - If `selling_plan.is_prepaid`:
           - `cycles_total = selling_plan.commitment_cycles` (e.g. 3, 6, 12).
           - `cycles_remaining = cycles_total - 1` (order 1 fulfills initial delivery).
         - Sets `next_delivery_date = today + 30 days` (or calculated interval).
         - Snapshots shipping address and unit price.
       - `execute_due_subscription_cycles(store=None, target_date=None)`:
         - Queries active subscriptions due on or before `target_date`.
         - Idempotency guard: skips if an order for this subscription was already generated today.
         - For prepaid plans:
           - Generates `Order(order_type="SUBSCRIPTION_CYCLE", subtotal_minor=0, shipping_minor=0, total_minor=0, status="CONFIRMED", payment_status="PAID", payment_method="KHALTI")`.
           - Generates corresponding `OrderItem`.
           - Appends `OrderEvent` ("Subscription fulfillment cycle generated").
           - Decrements `cycles_remaining`. If `cycles_remaining == 0`, sets `status="COMPLETED"`.
           - Advances `next_delivery_date`.
         - For pay-per-delivery plans:
           - Generates `Order(order_type="SUBSCRIPTION_CYCLE", total_minor=sub.unit_price_minor, status="PENDING_PAYMENT", payment_status="UNPAID")`.
           - Advances `next_delivery_date`.
    2. In `backend/stores/api.py`:
       - In `StoreKhaltiVerifyView`: if order contains subscription items or metadata, activate subscription via `create_subscription_from_order`.
       - Add `MerchantRunSubscriptionCyclesView` (`POST /api/merchant/stores/<storeSlug>/subscriptions/run-cycles/`):
         - Scoped to store owner/member. Runs `execute_due_subscription_cycles(store=store)` and returns generated orders count.
  </action>
  <verify>
    <automated>backend/venv/Scripts/python.exe backend/manage.py test accounts stores.tests.test_isolation</automated>
  </verify>
  <done>Subscription service created, wired to checkout verification, and verified with tests.</done>
</task>
