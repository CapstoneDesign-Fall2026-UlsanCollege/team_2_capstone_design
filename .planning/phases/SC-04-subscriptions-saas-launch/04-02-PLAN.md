  <action>
    1. In `backend/stores/api.py`:
       - `MerchantSubscriptionListView` (`GET /api/merchant/stores/<storeSlug>/subscriptions/`):
         - Scoped to store.
         - Computes metrics: `active_count`, `paused_count`, `completed_count`, `cancelled_count`, and `estimated_mrr_minor`.
         - Returns serialized subscription items with customer details, variant snapshot, selling plan details, next delivery date, and cycle counts.
       - `MerchantSubscriptionActionView` (`POST /api/merchant/stores/<storeSlug>/subscriptions/<int:subId>/action/`):
         - Actions: `pause`, `resume`, `skip_cycle`, `cancel`.
         - Validates state transitions (e.g. cannot resume CANCELLED or COMPLETED).
         - Returns updated subscription.
       - `ShopperSubscriptionListView` & `ShopperSubscriptionActionView`:
         - Customer-scoped endpoints for storefront shoppers.
    2. In `frontend/src/lib/api.ts`:
       - Add typed interfaces `SubscriptionDetail`, `SubscriptionMetricsResponse`.
       - Add API client methods: `fetchMerchantSubscriptions`, `triggerMerchantSubscriptionAction`, `runMerchantSubscriptionCycles`.
