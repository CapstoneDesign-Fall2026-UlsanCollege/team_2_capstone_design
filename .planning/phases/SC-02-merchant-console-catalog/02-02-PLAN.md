## Phase Goal

Enable any authenticated user to launch a new store and manage its branding, products, variants, Cloudinary images, selling plans, and Khalti payment credentials from a scoped merchant console.

<objective>
Implement store settings management at `/merchant/[storeSlug]/settings`: visual theme presets, delivery shipping rates, and encrypted Khalti gateway credentials per MERCH-04.
</objective>

       - If `khalti_secret_key` is provided in payload: calls `store.set_khalti_secret_key(raw_key)`.
