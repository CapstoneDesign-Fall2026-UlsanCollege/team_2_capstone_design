# ☕ BrewMellow: The Himalayan Coffee (Team 2 Capstone)

Welcome to the **BrewMellow: The Himalayan Coffee** repository! This project is being built for the Ulsan College Capstone Design course (Fall 2026).

We provide a seamless subscription service for high-quality, authentic Himalayan coffee directly to your door in Nepal.

---

## 📖 About the Project

BrewMellow: The Himalayan Coffee allows users to subscribe to recurring coffee deliveries. Customers can choose from premium regional beans (Gulmi, Ilam, Bharatpur, Kavrepalanchowk), select their preferred weight, and choose a subscription plan (pay-per-delivery or discounted 3/6/12 month commitments). 

Deliveries are scheduled every Monday, and the service includes a fully featured customer dashboard for pausing, skipping, and managing subscriptions.

## 🚀 Tech Stack

We are building a robust, scalable **Progressive Web App (PWA)** using the following technologies:

- **Frontend:** [Next.js](https://nextjs.org/) (React) + `next-pwa` (Deployed on Vercel)
- **Backend:** [Django](https://www.djangoproject.com/) + Django REST Framework (Deployed on DigitalOcean)
- **Database:** [PostgreSQL](https://www.postgresql.org/) (Hosted on Neon)
- **Payments:** [Khalti API](https://khalti.com/) integration
- **Notifications:** Automated Email Service (for delivery partners)

## ✨ Key Features

- **Origin Selection:** Choose beans based on scarcity and region (Gulmi, Ilam, etc.).
- **Flexible Pricing Model:** Discounts for upfront commitments (3-month, 6-month, annual).
- **Subscription Management:** Pause, skip, or cancel deliveries easily from the user dashboard.
- **Admin Control:** Django Admin panel for managing inventory, scarcity, user accounts, and pricing.
- **Holiday Handling:** Smart delivery scheduling that shifts Monday deliveries to the next day on public holidays.
- **Secure Authentication:** Email/password and phone number login support.
